Project overview

Moving a website without a redirect plan can break links and lose search traffic. This lab compares the old and new URL inventories, suggests matches, applies any explicit mappings, and reports what is missing, ambiguous, invalid, duplicated, chained or looping. It then prepares clean redirect rules for review.

It never visits the URLs. The findings shown in the animation are example content, not a real report.

Features

What it does.

Compares old and new URL lists

Up to 5,000 URLs per list, pasted in or loaded from a .txt or .csv file.

Smart matching

A unique matching path is offered as a suggestion, and explicit mappings always take precedence.

Optional redirect mappings

Source and destination rows, up to 5,000. Include existing rules to check them for chains and loops.

Finds redirect problems

Flags missing, ambiguous, invalid, duplicate, chained and looping redirects.

Clean final-destination rules

Builds chain-free redirect rules and marks them for human review.

Five exports

Vercel JSON, Apache .htaccess, Nginx config, a rules CSV and a findings CSV.

Paste or upload

Works with pasted lists and .txt or .csv uploads.

Safe, bounded and tested

It never visits the supplied URLs or crawls a site, saves no files, limits request size, and has automated Python and JavaScript tests.

How it works

From start to result.

  1. Add your URL lists

    Paste or load the old-site and new-site URLs.

  2. Add mappings

    Optionally add explicit redirects and existing rules.

  3. Run the comparison

    The Python backend validates and compares the routes.

  4. Review and export

    Check the findings, then export rules and test them on staging.
