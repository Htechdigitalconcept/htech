Project overview

Structured data helps search engines understand a business, but writing JSON-LD by hand is easy to get wrong. This builder asks for what you know, changes its fields to match the schema type, and produces a clean draft you can copy or download.

It runs entirely in the browser. The animation shown here is a demo of the output.

Features

What it does.

Six schema types

Organizations, businesses, services, websites, FAQs and breadcrumbs.

Fields that match the type

The form changes to fit the type you choose, so you only fill in what applies.

FAQ support

Add up to 10 real question and answer pairs from the page.

Breadcrumb trails

Page labels and canonical URLs, from the homepage to the page.

Copy or download

Copy the code or download a .jsonld file, with guidance on adding it to a page.

Private and free

Runs locally in the browser. Entries are not sent to Htech. No account and no paid API.

Honest guidance

Tells users to add only details they can verify, and that valid markup does not guarantee a rich result.

Automated tests

Tests cover the markup the builder generates.

How it works

From start to result.

  1. Choose a type

    Pick the description that fits the page.

  2. Fill in what you know

    Add only details you can verify.

  3. Generate JSON-LD

    Review the draft in the output panel.

  4. Copy and add it

    Place it on the matching page of your site.
